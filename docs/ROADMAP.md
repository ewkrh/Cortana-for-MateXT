# Roadmap

## M0 — Development Environment

**Status:** active

Goals:

- Android Studio installed
- Android SDK available
- ADB available
- Mate XT visible through `adb devices`
- minimal APK builds and installs

## M1 — Cortana Lab / Phone Control

**Status:** active

Goals:

- AccessibilityService
- UI hierarchy inspection
- normalized UI nodes
- node click
- swipe/scroll
- Back/Home
- MediaProjection screenshot
- debug UI
- real-device compatibility notes

Exit criterion:

All core capabilities verified on Huawei Mate XT / HarmonyOS 4.2.

## M2 — Tool Layer

**Status:** not started

Expose stable phone capabilities as AI-callable tools.

## M3 — Text AI Agent

**Status:** not started

Add text interaction and tool calling.

## M4 — Realtime Voice

**Status:** not started

Add streaming voice, interruption handling and conversational state.

## M5 — Autonomous Reading

**Status:** not started

Read long scrolling articles end-to-end and summarize them.

## M6 — Advanced Agent

**Status:** not started

Potential scope:

- multi-step tasks;
- cross-app workflows;
- screenshot + UI-tree perception;
- recovery from failed actions;
- memory and preferences;
- confirmation controls for sensitive actions.
